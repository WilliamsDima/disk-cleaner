# Чистка диска

Приложение для Windows, которое освобождает место на диске C. Показывает, что и сколько занимает, что будет после чистки, и удаляет только отмеченное галочками.

Сохранения игр, пароли, куки и ключи защищены на уровне ядра, даже если в правиле окажется ошибка. Подробнее: [docs/adr/0002-safety-model.md](docs/adr/0002-safety-model.md).

## Запуск

```
npm install
npm run package
```

Готовое приложение: `release/DiskCleaner-win32-x64/DiskCleaner.exe`. Устанавливать не нужно, папку можно положить куда угодно. Журналы чистки лежат в `%APPDATA%\DiskCleaner\logs`.
