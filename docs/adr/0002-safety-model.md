# 0002. Модель безопасности удаления

Дата: 2026-11-01. Статус: принято.

## Контекст

Ошибка в приложении может стоить пользователю сохранений игр, паролей или ключей. Удалённое не попадает в корзину. Одной проверки недостаточно: защита должна сработать, даже если ошибся автор правила.

## Решение

Несколько независимых рубежей. Каждый покрыт тестами.

| Рубеж                                           | Где                                          | От чего защищает                                                                            |
| ----------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Интерфейс передаёт только идентификаторы правил | `shared/contract.ts`, `CleanerService.clean` | Ошибка или взлом интерфейса не может указать путь                                           |
| Единый каталог правил                           | `rules/catalog.ts`                           | Удаление из неописанного места                                                              |
| Разрешённые корни                               | `isAllowedRoot`                              | Ошибка в пути правила, в том числе через `..`                                               |
| Защищённые пути и имена                         | `isProtected`                                | Правило случайно захватило сохранения, пароли, ключи                                        |
| Нет рекурсивного удаления                       | порт `FileSystem`                            | Удаление целого дерева одной ошибочной командой                                             |
| Ссылки не проходятся                            | `walk`, `runSpec`                            | Уход по junction за пределы разрешённой папки                                               |
| Отказ при неясности                             | правила, `runRule`                           | Удаление образа нужного эмулятора или рабочей версии программы                              |
| Проверка запущенных программ                    | `blockedBy`, `findBlockers`                  | Удаление файлов работающей программы. Если список процессов получить не удалось, чистки нет |
| План строится перед удалением                   | `runRule`                                    | Устаревшие результаты подсчёта                                                              |
| Подтверждение с фокусом на отмене               | `ConfirmDialog`                              | Случайное нажатие                                                                           |

## Последствия

- Иногда рядом с удалённым остаётся лишний файл, например `.pem` в папке старой версии программы. Это приемлемая плата: лучше оставить лишнее, чем удалить нужное.
- Занятые файлы пропускаются и не считаются ошибкой, поэтому освобождённый объём может быть меньше подсчитанного.
- Правила, которым нужны права администратора (WinSxS, `hiberfil.sys`), сознательно не поддерживаются.
