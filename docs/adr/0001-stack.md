# 0001. Electron, React и TypeScript

Дата: 2026-11-01. Статус: принято.

## Контекст

Нужно настольное приложение для Windows с современным интерфейсом. На компьютере разработки есть Node.js и опыт с React и TypeScript, но нет Rust, .NET и инструментов сборки Visual Studio.

## Решение

Electron, React и TypeScript, сборка через electron-vite, упаковка через `@electron/packager`.

## Варианты

- **Tauri.** Лучший размер: около 10 МБ против примерно 350 МБ. Требует Rust и инструменты сборки Visual Studio, это несколько гигабайт на диске C, который приложение и должно освобождать. Логику удаления пришлось бы писать на языке, с которым владелец проекта не работает.
- **WPF или WinUI на .NET.** Нативный вид, но нужен SDK и незнакомый стек.
- **PowerShell и WinForms.** Устанавливать ничего не нужно, но интерфейс выглядит устаревшим, а поддерживать и тестировать такой код трудно. Первый черновик был на этом стеке и отброшен.

## Последствия

- Приложение весит около 350 МБ, но лежит на диске E и установки не требует.
- Упаковка без подписи и установщика: для личного инструмента они не нужны, а `electron-builder` на Windows требует дополнительных прав.
- Если размер станет важен, ядро (`domain`, `application`, `rules`) и интерфейс не зависят от Electron, заменить придётся только `main/index.ts`, `preload` и `infrastructure`.
